# 실기기 검증 체크리스트 — `integration/2layer`

대상 기기: 갤럭시 S24 (SM-S921N) 외 실험 기기 3종

## 반드시 지킬 순서

`am force-stop`이나 재설치를 하면 Android가 안전장치로
`enabled_accessibility_services`를 지운다. 항상 **설치/force-stop → 접근성 서비스
재활성화 → 앱 실행** 순으로 할 것. `scripts/redeploy.sh`가 이 순서를 지킨다.

```bash
./scripts/redeploy.sh
adb logcat -s GurADian
```

수동으로 할 때:

```bash
SERVICE="com.guradian/com.guradian.service.GuardianAccessibilityService"
./gradlew installDebug
adb shell settings put secure enabled_accessibility_services "$SERVICE"
adb shell settings put secure accessibility_enabled 1
adb shell appops set com.guradian SYSTEM_ALERT_WINDOW allow
adb shell am start -n com.guradian/.MainActivity
```

### 2번이 이 브랜치의 핵심 회귀 지점

스크롤 추종 장치를 서비스에서 `BorderTracker`로 통째로 옮겼다. 상수와 로직은
한 글자도 안 바꿨지만 **옮기는 과정에서 깨졌는지는 눈으로만 확인된다.**
테두리가 옛 자리에 얼어붙거나, 스캔이 끝날 때마다 뒤로 튀거나, 깜빡이면 회귀다.

주사율 통일은 최종본 이후로 미뤘다. 기기마다 체감이 다른 것은 지금 단계에서는
정상이고, **한 기기 안에서 얼어붙거나 튀는 것**만 회귀로 본다.

### 8번을 빠뜨리면 스토어에 갇힌다

광고가 새 태스크로 스토어를 열면 `GLOBAL_ACTION_BACK`이 아무 일도 하지 않는다.
`[돌아가기]`를 누르고 1.5초 뒤에도 스토어 화면이면 홈으로 가야 한다.

## 로그로 확인할 것

```
layer2 판별기=GEMINI:gemini-3.1-flash-lite   ← 키가 있으면 이것
layer2 판별기=STUB                            ← 키가 없으면 이것 (오탐 주의)
layer2 출처=… 후보=… 캐시=… 판별=… 보류=… 표시=…
escape=STORE_REDIRECT com.android.vending
closed source=rule ok=true
```

`판별기=STUB`이면 지마켓 "슈퍼딜" 같은 쇼핑몰 자체 상품 영역을 광고로 오탐한다.
버튼을 눌러 부르는 구조에서는 사용자가 결과를 기다리므로 그 오탐이 그대로
평가받는다 — 시연 전에 `local.properties`의 `GEMINI_API_KEY`를 확인할 것.

## 함정

- **`uiautomator dump`는 다른 접근성 서비스를 꺼버린다** (`accessibility_enabled=0`).
  진단하려던 서비스를 진단 도구가 죽인다.
- **삼성 One UI는 일반 앱의 `Log.d`/`Log.v`를 억제한다.** `Log.i` 이상을 쓸 것.
- **Compose `Button`은 터치 클릭 시 `TYPE_VIEW_CLICKED`를 보내지 않는다.**
  설치 유도 감지를 테스트하려면 네이티브 View/WebView로 재현할 것.
- Git Bash에서 `/sdcard/...` 경로는 MSYS가 변환해버린다. `MSYS_NO_PATHCONV=1`.
